# 🏃 nano-HIIT

**nano-HIIT** est une application d'entraînement fractionné de haute intensité (HIIT) ultra-légère, conçue pour être rapide, autonome et respectueuse de votre vie privée.

## ✨ Caractéristiques

- **Ultra-légère :** L'application pèse moins de 100 Ko.
- **Mode Avion (✈️ OK) :** Une fois installée, elle fonctionne sans aucune connexion internet (PWA).
- **100% Respectueuse :** Pas de publicité, pas de cookies, pas de suivi (tracking), pas d'inscription.
- **Open Source :** Publiée sous licence MIT. Libre à vous de la consulter, de la modifier ou de la partager.

## 📲 Installation

Pour installer l'application sur votre smartphone :

1. Ouvrez [https://brunolaforet.github.io/nano-hiit/](https://brunolaforet.github.io/nano-hiit/) dans votre navigateur mobile.
2. **Sur Android (Chrome) :** Appuyez sur les trois points en haut à droite et sélectionnez **"Installer l'application"**.
3. **Sur iPhone (Safari) :** Appuyez sur l'icône de **partage** (carré avec une flèche) et choisissez **"Sur l'écran d'accueil"**.

## 🛠️ Développement

Cette application est une application web statique hébergée sur GitHub Pages.

- **Langages :** HTML5, CSS3, JavaScript (Vanilla).
- **Offline :** Utilisation d'un Service Worker pour la mise en cache.
- **Manifest :** Configuration PWA pour une expérience native.
